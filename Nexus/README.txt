Container Colors 1.2.0 for Kingdom Inc

Adds a color picker to the existing container and label options: hue, saturation/brightness,
hex RGB, opacity, and quick color swatches. Changes appear immediately.

REQUIREMENTS
Kingdom Inc, Unity Mono build; BepInEx 5 installed separately.

INSTALL / UPDATE
Close the game. Extract this archive into the KingdomInc game folder.
The plugin path must be BepInEx/plugins/ContainerColors/ContainerColors.dll.
Restart the game. Research Container Colors after Stickers, then open a
container or label's edit/options menu. Research costs 25% more than Stickers, rounded
up, using the same currencies and native prestige discounts.
Manual installation is supported. Vortex deployment has not been tested.

USE
Choose a hue, then a color in the saturation/brightness area, or enter six hex
digits such as #AF78E2 and press Enter. Opacity adjusts transparency. Changes
apply immediately. Native style buttons restore original colors. The Original
color button removes custom styling and uses its built-in fallback.

SAVES / REMOVAL
Custom RGBA data is stored alongside a valid built-in style. Cloning and
Sharable Blueprints preserve it with the plugin installed.
Close the game and delete the ContainerColors plugin folder to remove it.
Containers and labels load with a built-in fallback color and normal native opacity.
Saving without the plugin discards custom color metadata and its research unlock. Keep a save backup
if you plan to reinstall and want the exact custom colors back.
Label text editing and automatic sizing remain available. Stickers remain native.
Existing colors survive updates, but editing
custom colors now requires Container Colors research.

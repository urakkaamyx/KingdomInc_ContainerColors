Custom Container Colors 1.3.0 for Kingdom Inc

Choose any RGB color for containers and labels with a live color picker,
hex entry, opacity controls, and quick swatches.

INSTALL / UPDATE
Install the requirements listed on the Nexus page first:
https://www.nexusmods.com/kingdominc/mods/11
Close the game and extract this ZIP into the KingdomInc game folder.
Installed file: BepInEx/plugins/ContainerColors/ContainerColors.dll
Restart the game after installation or an update.

USE
Research Container Colors under Tech Tree > Mods after unlocking Stickers.
It costs 25% more than Stickers, rounded up, with the same currencies and
prestige discounts. Existing purchases remain unlocked after updating.
Open a container or label's edit/options menu. Choose a hue and color, or
enter six hex digits such as #AF78E2 and press Enter. Drag Opacity to adjust
transparency. Changes apply immediately.
Original swatches restore native styles. Original color uses the nearest
built-in fallback. Label text editing and automatic sizing remain available.

SAVES / REMOVAL
Colors and opacity persist when saving and copying decorations.
Close the game and delete BepInEx/plugins/ContainerColors to remove the mod.
Containers and labels load with built-in fallback colors and normal opacity.
Saving without the mod discards custom color data and its research unlock.
Keep a save backup if you want those exact colors after reinstalling.

[b]Custom Container Colors[/b]
Choose any RGB color for containers and labels in Kingdom Inc with a live color picker, hex entry, opacity controls and quick swatches.

[b]Features[/b]
[list]
[*]Hue, saturation and brightness controls with immediate preview.
[*]Six-digit hex RGB entry and adjustable opacity.
[*]Quick color swatches and the original five styles.
[*]Label text editing and automatic sizing stay available.
[*]Container borders, resizing, locking and anchoring stay available.
[*]Colors persist when saving and copying decorations.
[*]Built-in fallback colors keep containers and labels loadable after removal.
[/list]

[b]Research[/b]
Find Container Colors under [b]Tech Tree > Mods[/b] after unlocking Stickers. It costs 25% more than Stickers, rounded up, using the same currencies and prestige discounts. Existing research purchases remain unlocked after updating.

[b]Installation and updating[/b]
1. Install the dependencies listed in this page's Requirements section.
2. Close Kingdom Inc.
3. Extract the ZIP into the game folder beside KingdomInc.exe.
4. Confirm the file is at BepInEx/plugins/ContainerColors/ContainerColors.dll.
5. Restart the game.

[b]Using the picker[/b]
Open a container or label's edit/options menu. Choose a hue and then saturation and brightness, or enter six hex digits such as #AF78E2 and press Enter. Drag Opacity to adjust transparency. Changes apply immediately.
The original five swatches restore native styles. Original color removes custom styling and uses the nearest built-in fallback. The label text field remains above the picker. Stickers keep their original behavior.

[b]Removal and saves[/b]
Close the game and delete BepInEx/plugins/ContainerColors. Containers and labels load with built-in fallback colors and normal opacity.
[b]Saving without the mod discards custom color data and its research unlock.[/b] Keep a save backup if you want those exact colors available after reinstalling.
